CSS Typography & Web Fonts

Understanding font-family, font-size, font-weight, line-height, text-align — and how to use web fonts.

CSS · Typography · Fonts

1Introduction

Typography is the art and technique of arranging text so that it is readable, attractive, and communicates the right tone. In CSS, typography is controlled by a set of font-related properties that let you choose the font family, its size and weight, the spacing between lines, and how text is aligned.

Good typography is essential for a good website. Even a page with beautiful colors and layout will feel poor if the text is hard to read. The core typography properties are:

  • font-family — which typeface(s) to use.
  • font-size — how big the text is.
  • font-weight — how bold/thick the text is.
  • line-height — the vertical space between lines.
  • text-align — how text is lined up (left, center, right, justify).

By default, browsers use the fonts installed on the user's computer. But web fonts let you load a specific font from the internet (via the Google Fonts CDN, for example), so your page looks the same for every visitor, no matter what fonts their device has. This is what makes a site feel professional and consistent.

2Syntax and its Explanation

Here are the five core typography properties with their syntax and typical values.

PropertySyntaxExampleValues
font-familyfont-family: name(s)font-family: Arial, sans-serifComma-separated list of fonts; browser falls back to the next one.
font-sizefont-size: valuefont-size: 18pxpx, em, rem, %, keywords (small, large).
font-weightfont-weight: valuefont-weight: boldnormal/bold, or numbers 100–900.
line-heightline-height: valueline-height: 1.6A number (no unit) or a length like 24px.
text-aligntext-align: valuetext-align: centerleft, right, center, justify.

Example rule combining them

body {
  font-family: Arial, sans-serif;
  font-size: 18px;
  font-weight: normal;
  line-height: 1.6;
  text-align: left;
}
Key rule: Always end a font-family list with a generic fallback — sans-serif, serif, or monospace. This way, if none of the named fonts are available, the browser still has a sensible typeface to use.

3Features & Uses

1. font-family — choosing the typeface

Sets the font, with a fallback chain. Using a generic family at the end guarantees something will render.

h1 { font-family: Georgia, "Times New Roman", serif; }
p  { font-family: Helvetica, Arial, sans-serif; }

2. font-size — setting the size

Common units: px (fixed), rem (relative to root, good for accessibility), and em (relative to parent).

h1 { font-size: 2rem; }     // 2x the root size
p  { font-size: 16px; }

3. font-weight — thickness

Use keywords or numeric values (100 = thin, 400 = normal, 700 = bold, 900 = black).

h1 { font-weight: bold; }        // 700
strong { font-weight: 700; }
.light { font-weight: 300; }

4. line-height — spacing between lines

A ratio (e.g. 1.5) is most flexible and readable. This controls how "airy" or cramped the text feels.

body { line-height: 1.6; }   // comfortable reading
h1   { line-height: 1.2; }   // headings can be tighter

5. text-align — alignment

Aligns the inline/text content within its block container.

.center { text-align: center; }
.right  { text-align: right; }
.just   { text-align: justify; }

6. Web fonts — using fonts from the internet

A web font is loaded over the network using @font-face or, more simply, by importing from Google Fonts. Let's see the @font-face approach and the Google Fonts link method.

/* Method A: @font-face (load your own font file) */
@font-face {
  font-family: "MyFont";
  src: url("myfont.woff2") format("woff2");
}
body { font-family: "MyFont", sans-serif; }

/* Method B: Google Fonts (link in the <head>) — easiest */
/* <link href="https://fonts.googleapis.com/css2?family=Roboto&display=swap" rel="stylesheet"> */
body { font-family: "Roboto", sans-serif; }
Did you know? Since 2019, the default font stack of the "system" (like system-ui) uses the operating system's own fonts, which makes text load instantly and look native. It's a popular choice for modern websites.

4Example Programs with Explanation

Example 1 — All five typography properties in one page

This example applies font-family, font-size, font-weight, line-height, and text-align to different elements, so you can see each one in action.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <style>
    /* font-family + line-height on the whole page */
    body {
      font-family: Georgia, serif;
      line-height: 1.6;
    }

    /* font-size + font-weight on the heading */
    h1 {
      font-size: 2rem;
      font-weight: bold;
      text-align: center;
    }

    /* A lighter-weight paragraph, right aligned */
    .note {
      font-weight: 300;
      font-size: 0.9em;
      text-align: right;
    }
  </style>
</head>
<body>
  <h1>Typography in CSS</h1>
  <p>This paragraph uses the body's font (Georgia) and a comfortable
  line-height, making the text easy to read across several lines.</p>
  <p class="note">A smaller, right-aligned note.</p>
</body>
</html>
Explanation of Example 1:
  • font-family: Georgia, serif — applies the Georgia serif font, falling back to a generic serif.
  • line-height: 1.6 — gives comfortable spacing between lines of the paragraph.
  • h1 — font-size: 2rem makes it large, font-weight: bold makes it thick, and text-align: center centers it.
  • .note — lighter weight (300), smaller size (0.9em), and right-aligned.

Example 2 — Using a web font from Google Fonts

This example loads the popular "Roboto" font from Google Fonts and applies it to the page, so the text uses a specific web font rather than a system font. (You'll need an internet connection for the font to load.)

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">

  <!-- Load the Roboto web font from Google Fonts -->
  <link href="https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&display=swap" rel="stylesheet">

  <style>
    /* Use the loaded web font */
    body { font-family: "Roboto", sans-serif; }
    h1   { font-weight: 700; }
  </style>
</head>
<body>
  <h1>Hello, Web Fonts!</h1>
  <p>This text is rendered in the Roboto web font.</p>
</body>
</html>
Explanation of Example 2:
  • The <link> tag loads the font CSS from Google Fonts (weight 400 and 700).
  • font-family: "Roboto", sans-serif tells the browser to use Roboto, falling back to a generic sans-serif if it can't load.
  • Because Roboto is a web font, the same text look is guaranteed on every device, regardless of its installed fonts.
How to try it
Copy either example into a file named index.html and open it in a browser. Example 2 needs an internet connection to download Roboto — try removing the <link> line and you'll see it fall back to a plain sans-serif font instead. To load fonts locally, you'd use @font-face with your own .woff2 files.

5Advantages

  • Better readability: Good font choice, size, and line-height make text comfortable to read.
  • Professional look: Web fonts give a consistent, polished appearance across all devices.
  • Brand consistency: Using a font stack or a web font keeps typography consistent everywhere.
  • Improved accessibility: Using rem units and sensible sizes respect user zoom and readability settings.
  • Control over hierarchy: font-weight and font-size help establish a clear visual hierarchy (headings vs. body).
  • No images needed: Text is real, searchable, and selectable — far better than images for headings.

6Conclusion

CSS typography is about making text readable, clear, and attractive. The core properties — font-family, font-size, font-weight, line-height, and text-align — give you full control over how text looks and feels. And with web fonts, you can use any typeface you like, loaded from the internet, so your design is identical everywhere.

In summary: choose a clear font, size it appropriately, keep comfortable line spacing, and set alignment to suit the content. For a consistent brand look, pair a system-font fallback stack with a web font like Google Fonts. Typography is subtle, but it's one of the strongest signals of a well-made site. As the saying goes: "Typography is the craft of endowing human language with a durable visual form."
