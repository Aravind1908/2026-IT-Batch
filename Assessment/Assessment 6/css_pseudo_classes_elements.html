CSS Pseudo-classes & Pseudo-elements

Understanding the difference between :hover, :focus, :nth-child, :not — and ::before, ::after, ::first-line — with examples.

CSS · Selectors · Interaction

1Introduction

Sometimes you want to style an element based on a state it is in — like when the user hovers over a link, or when a field has focus — or style a part of an element, like just the first line of a paragraph. Regular selectors can't easily express these, so CSS provides two special kinds of selectors: pseudo-classes and pseudo-elements.

The key difference is easy to remember:

  • Pseudo-class (written with a single colon, like :hover) — selects an element in a particular state, or based on its position among its siblings. It styles the whole element but only in certain conditions.
  • Pseudo-element (written with a double colon, like ::before) — selects a specific part of an element that isn't a real element in the HTML, like the first line, or a decorative bit inserted before/after the content.

Think of it this way: a pseudo-class is a condition, while a pseudo-element is a piece. A pseudo-class asks "is the button hovered?" A pseudo-element says "insert something before this element's content."

2Syntax and its Explanation

Pseudo-classes (single colon)

selector:state { property: value; }
Pseudo-classSelectsExample
:hoverAn element the mouse is over.a:hover { color: red; }
:focusAn element currently focused (clicked/selected, e.g. an input).input:focus { border: 2px solid blue; }
:nth-child(n)The nth element among its siblings.li:nth-child(2) { ... }
:not(sel)Everything except the given selector.p:not(.highlight) { ... }

Pseudo-elements (double colon)

selector::part { property: value; }
Pseudo-elementSelectsExample
::beforeInserts content before an element's content.p::before { content: "★ "; }
::afterInserts content after an element's content.p::after { content: " ★"; }
::first-lineStyles just the first line of a block of text.p::first-line { font-weight: bold; }
Key rule: Pseudo-classes use a single colon (:hover) and style a whole element in a certain state. Pseudo-elements use a double colon (::before) and style or insert a part of an element. Crucially, ::before and ::after require a content property to be visible.

3Features & Uses

Pseudo-class: :hover

Styles an element when the pointer is over it (mouse hover / touch). Perfect for links, buttons, cards, and menus.

a:hover { color: #047857; text-decoration: underline; }
button:hover { background: #065f46; }

Pseudo-class: :focus

Styles an element while it has focus (keyboard or click). Excellent for accessible form fields — you can show a clear focus outline.

input:focus { outline: 3px solid #f59e0b; border-color: #f59e0b; }

Pseudo-class: :nth-child()

Targets the nth child among siblings. Useful for zebra striping, highlighting a specific item, or selectors based on position.

li:nth-child(2)   { color: red; }  // the 2nd li
li:nth-child(odd) { background: #eee; } // 1st, 3rd, 5th...
li:nth-child(even){ background: #fff; }

Pseudo-class: :not()

Selects everything except what matches the given selector. Great for "style all except the last one" or "except a certain class."

p:not(.highlight) { color: gray; }   // all p except .highlight
li:not(:last-child) { margin-bottom: 8px; }

Pseudo-element: ::before and ::after

Inserts decorative or helpful content before/after an element's actual content. They are commonly used for icons, quotes, labels, or separators. Remember: content is required.

p::before { content: "» "; color: teal; }
p::after  { content: " «"; color: teal; }
This note gets a "TIP:" prefix and an "(end of note)" suffix added by CSS pseudo-elements.

Pseudo-element: ::first-line

Styles only the first line of a block (like a paragraph). Note it only works on block-level elements.

p::first-line { font-weight: bold; color: #047857; }
Did you know? Pseudo-elements can be used to add icons and decoration without any extra HTML. For example, p::before { content: "★"; } adds a star before every paragraph — pure CSS, no extra tags.

4Example Programs with Explanation

Example 1 — Pseudo-classes in action

This example uses the four pseudo-classes: :hover on a button and link, :focus on a form-field, :nth-child() for zebra striping a list, and :not() to style everything except the highlighted paragraph.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <style>
    /* :hover — change when the pointer moves over the element */
    button:hover { background: #065f46; }

    /* :focus — highlight a focused field with a clear outline */
    input:focus { outline: 3px solid #f59e0b; }

    /* :nth-child() — zebra stripe a list */
    li:nth-child(odd)  { background: #e4f4ee; }
    li:nth-child(even) { background: #fff; }

    /* :not() — style everything EXCEPT .highlight */
    p:not(.highlight) { color: gray; }

    body { font-family: Arial, sans-serif; }
  </style>
</head>
<body>
  <button>Hover me</button>
  <br><br>
  <input type="text" placeholder="Click here to focus">
  <ul>
    <li>Item 1</li>
    <li>Item 2</li>
    <li>Item 3</li>
    <li>Item 4</li>
  </ul>
  <p>This is normal, grey text.</p>
  <p class="highlight">This is highlighted, so it stays dark.</p>
</body>
</html>
Explanation of Example 1:
  • button:hover — darkens the button when the mouse is over it.
  • input:focus — adds an orange outline when the field is focused (clicked/tabbed into).
  • li:nth-child(odd) / even — creates a zebra-striped list (alternating backgrounds).
  • p:not(.highlight) — makes all paragraphs grey except the one with class="highlight", which stays dark.

Example 2 — Pseudo-elements in action

This example shows ::before and ::after adding a star icon before and after each heading, and ::first-line styling the first line of the paragraph in bold and color.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <style>
    /* ::before — add a star BEFORE each heading's text */
    h2::before { content: "★ "; color: #047857; }

    /* ::after — add a label AFTER each heading */
    h2::after  { content: " ◆"; color: #f59e0b; }

    /* ::first-line — bold & color the first line of the paragraph */
    p::first-line { font-weight: bold; color: #047857; }

    body { font-family: Georgia, serif; }
  </style>
</head>
<body>
  <h2>Section One</h2>
  <p>This is a long line of text that will wrap onto several lines,
  and only the first line is colored and bolded by ::first-line.
  The rest of the paragraph continues in normal text styling.</p>
  <h2>Section Two</h2>
  <p>Another paragraph here.</p>
</body>
</html>
Explanation of Example 2:
  • h2::before inserts "★ " before each heading's text — no extra HTML needed.
  • h2::after inserts " ◆" after the heading text, acting as a decorative label.
  • p::first-line styles only the first line of the paragraph, letting the rest remain normal.
  • Both pseudo-elements required a content property (except ::first-line, which styles existing text).
How to try it
Copy either example into a file named index.html and open it in a browser. Hover the button, tab into the field, and resize the browser window so Example 2's paragraph wraps — you'll see only the first line change color.

5Advantages

  • More dynamic styling: Pseudo-classes respond to the user's interaction (hover, focus) for a lively feel.
  • No extra HTML: Pseudo-elements add content and decoration purely in CSS (::before/::after).
  • Cleaner markup: Express states/structure in CSS rather than adding classes or spans.
  • Better accessibility: :focus styling makes keyboard navigation clearly visible.
  • Flexible & powerful: :nth-child() and :not() let you target positions and exclusions precisely.
  • Less repetition: One rule can cover an entire category of conditions (e.g., all odd rows).

6Conclusion

Pseudo-classes and pseudo-elements let you style conditions and parts of elements that a plain selector can't reach. Use the single-colon pseudo-classes — :hover, :focus, :nth-child(), :not() — to target an element based on its state or position. Use the double-colon pseudo-elements — ::before, ::after, ::first-line — to insert or style a part of an element.

In summary: pseudo-class = condition, pseudo-element = part. Master both, and you'll write less HTML, create more polished interactions, and build more accessible pages. As the saying goes: "With pseudo-selectors, CSS reaches parts of the page that HTML never touches."
