Types of CSS Positioning

A complete guide to the five position values — static, relative, absolute, fixed, and sticky — with syntax and examples.

CSS · Layout · Positioning

1Introduction

The position property is one of the most powerful layout tools in CSS. It controls where an element sits on the page, and — combined with the offset properties top, right, bottom, and left — it lets you place elements exactly where you want them, or even pull them out of the normal flow.

By default, elements are laid out in a "normal flow" — the browser stacks block elements on top of each other and flows inline elements left to right. The position property lets you change that. There are five values, each easier to understand by contrasting them:

  • static — the default; the element stays exactly where normal flow puts it. Offsets have no effect.
  • relative — still in normal flow (keeps its space), but can be nudged from where it would have been.
  • absolute — removed from normal flow and positioned relative to its nearest positioned ancestor (or the page).
  • fixed — removed from normal flow and positioned relative to the viewport, so it stays on screen even when scrolling.
  • sticky — a hybrid; it behaves like relative until you scroll past a threshold, then behaves like fixed.

2Syntax and its Explanation

The base syntax is simple — set position and optionally supply offsets:

element {
  position: value;   // static | relative | absolute | fixed | sticky
  top: value;        // optional offset
  right: value;
  bottom: value;
  left: value;
}

Key rule: Offsets like top/left only take effect on positioned elements (anything except static). For absolute elements, the "reference" is the nearest ancestor that is itself positioned (has position other than static). For fixed, the reference is always the viewport.

3Features & Uses

1. static — the default

Every element is static by default. It flows normally and ignores top/left. You rarely set this explicitly, but it's the baseline to compare others against.

div { position: static; }  // default; no offsets work

2. relative — nudge without affecting others

The element keeps its place in the flow (other elements don't move), but you can shift it visually with offsets. It also becomes the "reference" for any absolutely-positioned children.

.box {
  position: relative;
  top: 20px;   // moves down 20px from where it would be
  left: 10px;  // moves right 10px
}

3. absolute — place precisely within a parent

The element is removed from flow and positioned relative to the nearest positioned ancestor (or the page if none). It no longer takes up space, letting you overlay content.

.parent { position: relative; }    // sets the reference
.child  {
  position: absolute;
  top: 0; left: 0; // pinned to parent's top-left
}

4. fixed — stay on screen

The element is positioned relative to the viewport and does not move when you scroll. Ideal for fixed headers, nav bars, cookie banners, or "back to top" buttons.

nav {
  position: fixed;
  top: 0; left: 0;
  width: 100%;   // a full-width top bar
}

5. sticky — stick while scrolling

Behaves like relative until the element reaches a scroll threshold, then fixed-like. Great for sticky table headers, section headers, or toolbars.

th {
  position: sticky;
  top: 0;   // sticks to the top once scrolled to
}
Did you know? When you use absolute/fixed/sticky and things overlap, you control which element sits on top with z-index. Higher z-index appears "above." (Only works on positioned elements.)

4Example Programs with Explanation

Example 1 — static, relative, and absolute together

This example places a parent .wrap as relative, then puts normal-flow boxes (static), a nudged box (relative), and an overlaid box (absolute) inside it. This shows how the three interact.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <style>
    /* A positioned parent — reference for the absolute child */
    .wrap {
      position: relative;
      width: 300px; height: 200px;
      border: 2px solid #b91c1c;
      background: #fce7e7;
    }

    /* static — normal flow, takes its space */
    .static { position: static; background: #fde68a; padding: 6px; }

    /* relative — keeps its slot but shifts down 20px */
    .relative {
      position: relative;
      top: 20px; left: 10px;
      background: #93c5fd; padding: 6px;
      color: black;
    }

    /* absolute — removed from flow, pinned to wrap's top-right */
    .absolute {
      position: absolute;
      top: 0; right: 0;
      background: #b91c1c; color: white; padding: 6px;
    }
  </style>
</head>
<body>
  <div class="wrap">
    <div class="static">Static</div>
    <div class="relative">Relative</div>
    <div class="absolute">Absolute</div>
  </div>
</body>
</html>
Explanation of Example 1:
  • .wrap with position: relative becomes the reference point for absolutely-positioned children.
  • .static flows normally and stays in its natural place.
  • .relative still occupies its normal slot but is nudged down 20px and right 10px.
  • .absolute is pulled out of the flow and pinned to the top-right corner of .wrap (because wrap is its positioned ancestor).

Example 2 — fixed and sticky

This example demonstrates a fixed header that stays at the top while scrolling, and a sticky heading that sticks once it reaches the top. Scroll the page to see them both behave.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <style>
    /* Fixed header — stays pinned to the top of the viewport */
    header {
      position: fixed;
      top: 0; left: 0;
      width: 100%;
      background: #b91c1c; color: white;
      padding: 12px;
    }

    /* Sticky heading — scrolls normally, then sticks at the top */
    h2.sticky {
      position: sticky;
      top: 60px;  // sticks just below the fixed header
      background: #fce7e7;
      padding: 8px;
    }

    /* Just some content to scroll through */
    .content { padding: 80px 20px 200px; }
  </style>
</head>
<body>
  <header>Fixed Header (stays on screen)</header>

  <div class="content">
    <h2 class="sticky">Sticky Heading</h2>
    <p>Scroll down to see the sticky heading "stick" to the top, while
    the fixed header stays put at the very top the whole time.</p>
    <p>More content to give the page length...</p>
    <p>Keep scrolling to notice the difference between fixed and sticky.</p>
  </div>
</body>
</html>
Explanation of Example 2:
  • header with position: fixed is pinned to the top of the viewport and never scrolls away.
  • h2.sticky with position: sticky scrolls with the page until it reaches top: 60px, then "sticks" there as you keep scrolling.
  • top: 60px for the sticky heading positions it just below the fixed header so they don't overlap.
  • This is the classic pattern for a fixed navbar with a sticky section header.
How to try it
Copy either example into a file named index.html and open it in a browser. Example 1 shows layout positioning inside a parent; Example 2 needs you to scroll to see the fixed header stay put and the sticky heading catch up. Try changing the top values to see the effect.

5Advantages

  • Precise control: Position elements exactly where you need them on the page.
  • Overlay & layering: Use absolute to overlay content, badges, or labels on top of images/cards.
  • Persistent navigation: fixed keeps menus or action buttons always visible for a smoother UX.
  • Better scrolling experience: sticky keeps important headers in view without removing them from flow.
  • Reference system: Pairing relative parents with absolute children is the foundation of many layouts (e.g., profile pictures with badges).
  • Interactive design: Offset properties plus z-index let you build rich, multi-layered designs.

6Conclusion

CSS positioning gives you complete control over where elements sit. The static value is the default that flows normally; relative nudges an element while keeping its space; absolute removes it from the flow and places it relative to a positioned parent; fixed pins it to the viewport so it never scrolls away; and sticky combines both by scrolling normally until it "sticks."

In summary: use relative for the parent and small nudges, absolute for precise overlays, fixed for always-visible bars, and sticky for headers that should follow you. Understanding these five values, along with offsets and z-index, unlocks the full power of CSS layout. As the saying goes: "Master positioning, and you can place anything anywhere."
