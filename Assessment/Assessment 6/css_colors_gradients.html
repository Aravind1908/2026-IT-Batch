CSS Colors, Backgrounds & Gradients

A complete guide to color notations, background properties, and linear & radial gradients — with examples.

CSS · Colors · Gradients

1Introduction

Color is one of the most powerful design tools in CSS. It can set the mood of a page, highlight important elements, and guide the user's eye. CSS gives you several ways to describe the same color, plus full control over backgrounds and gradients.

There are four common color notations:

  • Named colors — a set of predefined names like red, teal, gold (about 140 of them).
  • Hex codes — a six-digit code starting with #, like #ff5733.
  • rgb() — red, green, blue values, each 0–255, like rgb(255, 87, 51).
  • hsl() — hue, saturation, lightness, like hsl(9, 100%, 60%).

Beyond colors, you can style an element's background (color, image, position, size, repeat) and even create smooth transitions between colors using gradients — linear or radial. Together these let you build visually rich, professional-looking pages.

Background properties

background-color:#ff5733;
background-image:url("bg.jpg");
background-repeat: no-repeat;   // or repeat, repeat-x, repeat-y
background-position: center;
background-size: cover;
background: #0f766e url("bg.jpg") no-repeat center;

Gradients

/* Linear gradient: colors go in a straight line */
background: linear-gradient(red, blue);
background: linear-gradient(45deg, #ff5733, #ffc300);

/* Radial gradient: colors spread out from a center point */
background: radial-gradient(circle, #fff, #0f766e);
Key rule: All four notations can produce the exact same color — it's just a different way of writing it. Choose the notation that is clearest in context: named colors for readability, hex for precision, rgb for numbers, and hsl for adjusting lightness/hue easily.

3Features & Uses

1. Named colors — simple & readable

Perfect for quick, understandable styles. There are about 140 supported names (including transparent).

h1 { color: tomato; }
.box { background-color: lightgray; }

2. Hex colors — the most common in design

A 6-digit code (or 3-digit shorthand) for precise control. Each pair of digits is red, green, blue in hexadecimal (00–ff, i.e. 0–255). You can also add two more digits for alpha (opacity).

body { background-color: #f6f8fb; }
h2  { color: #0f766e; }
button { background: #ff5733; color: #ffffffcc; }

3. rgb() — values as numbers

Red, green, blue each from 0 to 255. Adding a fourth value (alpha) makes the color semi-transparent.

p { color: rgb(15, 118, 110); }
.overlay { background: rgba(0, 0, 0, 0.5); }  // 50% black

4. hsl() — easiest to tweak

Hue is an angle on the colour wheel (0–360), saturation and lightness are percentages. Because lightness is separate, it's very easy to darken or lighten a color just by changing l%.

h1 { color: hsl(174, 78%, 26%); }  // teal

h2 { color: hsl(9, 100%, 50%); }

5. Background properties

Style the area behind an element — its color, and optionally a background image with control over repeat, position, and size.

.hero {
  background-color: #0f766e;
  background-image: url("banner.jpg");
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover;
}

6. Linear gradient

Colors blend along a straight line. You can specify a direction (angle or to-side) and any number of color stops.

background: linear-gradient(90deg, #ff5733, #ffc300);
background: linear-gradient(to bottom, #0f766e, #115e59);

7. Radial gradient

Colors spread outward from a center point, like ripples in water.

background: radial-gradient(circle, #fff, #0f766e);
background: radial-gradient(#ffc300, #ff5733);
Did you know? You can also make gradients repeating with repeating-linear-gradient(), and you can layer multiple backgrounds by separating them with commas, e.g. background: linear-gradient(...), url(...).

4Example Programs with Explanation

Example 1 — Using all four color notations

This example uses a named color, a hex color, an rgb color, and an hsl color — one for each of four elements — so you can compare them side by side. All four produce visible colors on the page.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <style>
    /* A named color */
    p.named { color: teal; }

    /* A hex color */
    p.hex { color: #ff5733; }

    /* An rgb color (with faint background) */
    p.rgb { color: rgb(15, 118, 110); }

    /* An hsl color (with faint background) */
    p.hsl { color: hsl(9, 100%, 58%); }
  </style>
</head>
<body>
  <p class="named">This is named color: teal</p>
  <p class="hex">This is hex color: #ff5733</p>
  <p class="rgb">This is rgb: rgb(15, 118, 110)</p>
  <p class="hsl">This is hsl: hsl(9, 100%, 58%)</p>
</body>
</html>
Explanation of Example 1:
  • teal — uses a named color, easiest to read.
  • #ff5733 — uses a hex code, precise and common in design.
  • rgb(15, 118, 110) — uses rgb() with numeric red/green/blue values.
  • hsl(9, 100%, 58%) — uses hsl() with hue, saturation, and lightness.
  • All four are valid and produce a color; the difference is only in how you express it.

Example 2 — Background properties + linear & radial gradients

This example shows a hero section with a background image (simulated), then compares a linear gradient and a radial gradient side by side using the background shorthand.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <style>
    /* A hero with a background color + image, centered & covered */
    .hero {
      background-color: #0f766e;
      background-image: url("banner.jpg");
      background-repeat: no-repeat;
      background-position: center;
      background-size: cover;
      color: white; padding: 40px;
    }

    /* A linear gradient box */
    .linear {
      background: linear-gradient(90deg, #ff5733, #ffc300);
      color: white; padding: 30px;
    }

    /* A radial gradient box */
    .radial {
      background: radial-gradient(circle, #ffc300, #db2777);
      color: white; padding: 30px;
    }
  </style>
</head>
<body>
  <div class="hero">Hero section with background image</div>
  <div class="linear">Linear gradient (left to right)</div>
  <div class="radial">Radial gradient (from center)</div>
</body>
</html>
Explanation of Example 2:
  • .hero uses separate background-color, background-image, repeat, position, and size properties (here the image is a placeholder — replace with a real image to see it).
  • .linear uses linear-gradient(90deg, ...) — colors flow left to right.
  • .radial uses radial-gradient(circle, ...) — colors spread out from the center in a circle.
  • The background shorthand lets you set color, image, repeat, position, and size all at once.
How to try it
Copy either example into a file named index.html and open it in a browser. In Example 2, you can drop any image named banner.jpg in the same folder to see the background-image property in action. Try changing the gradient angle or colors to see how easily they update.

5Advantages

  • Flexibility & precision: Multiple notations let you express colors exactly as you need them.
  • Readability: Named colors and hsl make code easier to read and tweak.
  • Consistency: Hex and rgb give exact, repeatable colors across your whole site.
  • Rich backgrounds: Background properties let you place, repeat, and size backgrounds precisely.
  • Professional look with gradients: Linear and radial gradients create smooth, attractive visuals without images.
  • No extra assets: Gradients are pure CSS — fast, scalable, and responsive with no image files to load.

6Conclusion

CSS color is built on four interchangeable notations — named, hex, rgb, and hsl — each letting you describe the same color a different way. With the background properties you can add color and images behind any element, and with linear and radial gradients you can blend colors into smooth, eye-catching designs.

In summary: pick the notation that reads best, control your backgrounds precisely, and use gradients to create depth and atmosphere without images. These tools give you full artistic control over how a page looks. As the saying goes: "Color is the silent language of the web — learn to speak it fluently."
