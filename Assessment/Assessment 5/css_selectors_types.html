Types of CSS Selectors

A complete guide to element, class, id, attribute, combinator, and universal selectors — with syntax and examples.

CSS · Selectors · Styling

1Introduction

A CSS selector is the part of a CSS rule that selects which HTML elements to style. It is how you say "make every heading blue" or "style only the first paragraph." Without selectors, CSS would have no way of knowing which parts of a page to apply rules to.

A CSS rule has two parts: 

selector {
  property: value;
}

The selector targets elements, and the declaration block (inside the curly braces) tells the browser what to change about them. This guide covers the most important selector types you'll use every day.

  • Element selectors — by tag name.
  • Class selectors — by a class attribute.
  • ID selectors — by an id attribute.
  • Attribute selectors — by an attribute or its value.
  • Combinators — descendant, child, and sibling.
  • Universal selector — everything.

Key rule: A selector's "specificity" matters. If two rules conflict, the one with higher specificity wins. In general, id > class > element, and combinators/attribute selectors fall roughly between class and element. The * universal selector has the lowest specificity.

3Features & Uses

1. Element selector — by tag name

Selects every element of a given type. Great for setting default styling for a whole tag (e.g., all headings or all links).

h2  { color: teal; }
p   { line-height: 1.6; }
a   { text-decoration: none; }

2. Class selector — the most common

Selects elements that share a class. A class can be reused on many elements, making it the most flexible and widely-used selector.

<!-- HTML -->
<p class="highlight">Hello</p>
<p class="highlight">World</p>

/* CSS */
.highlight { background: yellow; }

3. ID selector — one unique element

Selects a single, unique element (an id can only be used once per page). Useful for targeting one special element like a header, footer, or the main container.

<!-- HTML -->
<div id="main">Content</div>

/* CSS */
#main { max-width: 800px; margin: auto; }

4. Attribute selector — by an attribute

Selects elements based on an attribute, its value, or part of its value. Useful for styling inputs of a certain type, or links with a specific attribute.

input[type="email"]   { border: 2px solid teal; }
a[href^="https"]        { color: green; }  // href starts with https

5. Descendant combinator (space)

Selects an element that is anywhere inside another element, at any level of nesting.

/* Select any p inside a div, even nested deep */
div p { font-size: 18px; }

6. Child combinator (>)

Selects an element that is a direct child of another — not a deeper grandchild.

/* Only the li that are DIRECT children of ul */
ul > li   { list-style: none; }

7. Sibling combinators (~ and +)

Select elements on the same level (sharing the same parent).

/* General sibling: any p after an h1 */
h1 ~ p { color: gray; }

/* Adjacent sibling: the p immediately after an h1 */
h1 + p { font-weight: bold; }

8. Universal selector (*)

Selects every element on the page. Commonly used for quick resets, such as removing default margins and padding.

/* A common reset */
* { margin: 0; padding: 0; box-sizing: border-box; }
Did you know? You can combine selectors by using a comma, e.g. h1, h2, h3 { font-weight: bold; } applies the rule to all three at once — this is called a selector list.

4Example Programs with Explanation

Example 1 — A page demonstrating every selector type

This example applies every selector we learned in one file. Open it and notice which parts of the page get styled by each rule.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <style>
    /* Universal: apply to everything */
    * { box-sizing: border-box; }

    /* Element selectors */
    h2   { color: #0f766e; }
    p    { line-height: 1.6; }

    /* Class selector */
    .box { padding: 10px; border: 1px solid #ccc; }

    /* ID selector */
    #main { max-width: 600px; margin: auto; }

    /* Attribute selector */
    input[type="email"] { border: 2px solid teal; }

    /* Descendant: p inside #main */
    #main p { color: #444; }

    /* Child combinator */
    ul > li { list-style: none; }

    /* Adjacent sibling */
    h2 + p { font-weight: bold; }
  </style>
</head>
<body>
  <div id="main">
    <h2>Title</h2>
    <p>This paragraph is bold (adjacent to h2).</p>
    <p class="box">This has the .box class.</p>
    <input type="email" placeholder="Email">
    <ul><li>Item 1</li><li>Item 2</li></ul>
  </div>
</body>
</html>
Explanation of Example 1:
  • * sets box-sizing on everything.
  • h2 and p are element selectors.
  • .box is a class selector (applies to the paragraph with class="box").
  • #main is an id selector (the outer container).
  • input[type="email"] is an attribute selector.
  • #main p is a descendant selector.
  • ul > li is a child selector removing bullets.
  • h2 + p is an adjacent sibling selector making that first paragraph bold.

Example 2 — Styling a layout with combinators

This example focuses on combinators. It builds a simple card layout and uses descendants, child, and sibling selectors to style the structure cleanly.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <style>
    /* Descendant: style the title inside a card */
    .card h2  { margin: 0; font-size: 20px; }

    /* Child: give each direct card its own rule via the container */
    .cards > .card { background: #f6f8fb; padding: 16px; }

    /* General sibling: grey the paragraphs that follow a heading */
    .card h2 ~ p { color: #666; }

    /* Adjacent sibling: space between heading and first paragraph */
    .card h2 + p { margin-top: 8px; }
  </style>
</head>
<body>
  <div class="cards">
    <div class="card">
      <h2>Card One</h2>
      <p>This is the first paragraph.</p>
      <p>Second paragraph, greyed by `~`.</p>
    </div>
    <div class="card">
      <h2>Card Two</h2>
      <p>Second card content.</p>
    </div>
  </div>
</body>
</html>
Explanation of Example 2:
  • .card h2 — a descendant selector styling the heading inside each card.
  • .cards > .card — a child selector applying the background to direct card children only.
  • .card h2 ~ p — a general sibling selector greying all paragraphs that follow a heading.
  • .card h2 + p — an adjacent sibling selector adding space to the paragraph right after the heading.
How to try it
Copy either example into a file named index.html and open it in a browser. Remember, this validates the CSS, and you can open DevTools (F12) to inspect which rule is applied to each element. Change a selector and refresh to see the effect.

5Advantages

  • Precise targeting: Selectors let you style exactly what you want — one element, a group, or a special case.
  • Less HTML, more CSS: You can style many elements without adding classes/ids to each one.
  • Cleaner, maintainable code: Well-chosen selectors reduce repetition and make styles easier to update.
  • Powerful structure control: Combinators (descendant, child, sibling) let you style based on the document's hierarchy.
  • Reusable styles: Classes and attribute selectors allow the same styling to apply across many elements.
  • Standard & widely supported: All of these are core CSS and work in every modern browser.

6Conclusion

CSS selectors are the bridge between your HTML and your styles. From the simple element selector, through class and id, to the more advanced attribute, combinator (descendant, child, sibling), and universal selectors — each gives you a different way to target the parts of a page you want to style.

In summary: use element for defaults, .class for reusable groups, #id for one-off elements, [attribute] for attributes, combinators for structure, and * for resets. Mastering these, along with understanding specificity, makes you a confident and efficient CSS author. As the saying goes: "If you can select it, you can style it."
