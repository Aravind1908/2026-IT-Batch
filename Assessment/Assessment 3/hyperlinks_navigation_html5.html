Hyperlinks & Navigation in HTML5

A complete guide to the anchor tag — internal, external, email, and anchor links, plus the target attribute.

HTML5 · Links · Navigation

1Introduction

The hyperlink is the single feature that makes the web a "web." It is what connects one page to another, letting a user click and jump from anywhere to anywhere. Without links, a website would just be a collection of isolated documents.

In HTML, a link is created with the anchor tag: <a> (short for "anchor"). You wrap the text or image that should be clickable between the opening and closing tags, and you set the destination using the href attribute. The basic syntax is: 

<a href="destination">Clickable text</a>

Depending on what you put in href, you can create several different kinds of links:

  • Internal links — jump to another page on your own website.
  • External links — jump to a page on a different website.
  • Email links — open the visitor's email program with a message ready to send.
  • Anchor links — jump to a specific section within the same page.

You can also control where the link opens — in the same tab or a new one — using the target attribute.

2Syntax and its Explanation

The general structure of the anchor tag is:

<a
  href="destination"      <!-- WHERE to go -->
  target="_self"              <!-- WHERE to open it -->
  title="tooltip text"       <!-- extra info on hover -->
> Clickable text </a>

The most important attributes

AttributePurposeExample
hrefThe destination URL (or path) the link goes to. This is the only required attribute.href="page2.html"
targetControls where the link opens (_self, _blank, _parent, _top).target="_blank"
titleShows a tooltip when the user hovers over the link.title="Go to Google"
relDescribes the relationship to the target (e.g. nofollow, noopener).rel="noopener"

The four kinds of href

TypeSyntaxWhat it does
Internalhref="about.html" or href="page.html"Links to a page on the same site.
Externalhref="https://example.com"Links to a page on another site.
Emailhref="mailto:[email protected]"Opens the user's email app addressed to that address.
Anchorhref="#section-id"Scrolls to an element with that id on the same page.
Key rule: Every link needs a href. The href determines the type of link, while target determines where it opens. To use an anchor link, the destination element must have a matching id attribute.

3Features & Uses

Each type of link serves a different purpose. Let's look at them, one by one, with examples.

1. Internal links — navigating your own site

These connect pages within your own website. They are the heart of site navigation (menus, footer links, "next" buttons).

<a href="index.html">Home</a>
<a href="about.html">About Us</a>

2. External links — pointing to other sites

These point to a full URL on another website. Use the complete protocol (https://) so the browser knows where to go.

<a href="https://www.w3.org">Visit W3C</a>

3. Email links — ready-to-send messages

Use the mailto: scheme. You can even pre-fill the subject and body by adding them after a question mark.

<a href="mailto:[email protected]">Email us</a>
<a href="mailto:[email protected]?subject=Hello&body=Hi there">Email with a subject</a>

4. Anchor links — jump within the same page

The href starts with a # and points to an element's id. This is great for "back to top" buttons, a table of contents, or section navigation.

<!-- The destination element needs an id -->
<h2 id="about">About</h2>

<!-- The link points to that id -->
<a href="#about">Go to About</a>

5. The target attribute — where the link opens

The target attribute tells the browser where to display the linked page.

<!-- Default: opens in the same tab -->
<a href="page.html" target="_self">Same tab</a>

<!-- Opens in a new tab/window -->
<a href="https://example.com" target="_blank">New tab</a>
Did you know? When opening a link in a new tab (target="_blank"), it is good practice to add rel="noopener" — it prevents the new page from accessing the page you came from, keeping things more secure.

4Example Programs with Explanation

Example 1 — All four link types on one page (with anchor scrolling)

This example puts together every type of link. It has a <nav> menu with internal and external links, an email link, and anchor links that scroll to sections on the same page.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Link Examples</title>
</head>
<body>

  <!-- Anchor links: jump to section ids on THIS page -->
  <nav>
    <a href="#home">Home</a> |
    <a href="#about">About</a> |
    <a href="#contact">Contact</a>
  </nav>

  <!-- Internal link: another page on the same site -->
  <p><a href="page2.html">Go to page 2 (internal)</a></p>

  <!-- External link + opens in a new tab -->
  <p><a href="https://www.google.com" target="_blank" rel="noopener">
    Google (external, new tab)</a></p>

  <!-- Email link -->
  <p><a href="mailto:[email protected]?subject=Hello">
    Email us (mailto)</a></p>

  <!-- Sections for the anchor links to target -->
  <h2 id="home">Home</h2>
  <h2 id="about">About</h2>
  <h2 id="contact">Contact</h2>

</body>
</html>
Explanation of Example 1:
  • Anchor links — the nav uses #home, #about, #contact, which scroll down to the matching id headings.
  • Internal link — href="page2.html" points to another file on the same site.
  • External link — points to a full https:// URL, opens in a new tab via target="_blank", and uses rel="noopener" for security.
  • Email link — mailto: opens the visitor's email app, pre-filled with a subject.

Example 2 — A styled navigation bar with all link types

This example shows a real site header: a horizontal navigation menu made of links, combining internal links, an external link, and an email link, all styled with a little CSS.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <style>
    /* Style the nav bar */
    nav { background: #333; padding: 10px; }
    nav a { color: white; margin-right: 15px; text-decoration: none; }
    nav a:hover { color: #0d9488; }
  </style>
</head>
<body>

  <nav>
    <a href="index.html">Home</a>          <!-- internal -->
    <a href="products.html">Products</a>   <!-- internal -->
    <a href="#top">Back to Top</a>     <!-- anchor -->
    <a href="https://github.com" target="_blank">GitHub</a>  <!-- external, new tab -->
    <a href="mailto:[email protected]">Support</a> <!-- email -->
  </nav>

  <p id="top">Scroll down to see the page content, then click "Back to Top".</p>

</body>
</html>
Explanation of Example 2:
  • The <nav> element contains all the links, and CSS turns them into a clean horizontal menu.
  • index.html and products.html are internal links to same-site pages.
  • #top is an anchor link pointing to the <p id="top"> element further down the page.
  • https://github.com is an external link that opens in a new tab.
  • mailto:[email protected] is an email link that opens the visitor's mail app.
How to try it
Save Example 1 as index.html (and make a page2.html in the same folder for the internal link). Open it and click each link. For the anchor links, create enough content so the page scrolls; "Back to Top" will jump back up.

5Advantages

  • Easy user navigation: Links let visitors move effortlessly between pages and sections.
  • Great for SEO: Search engines follow links to discover and index your pages; a good link structure improves ranking.
  • Multiple link types in one tag: The same <a> element handles internal, external, email, and anchor destinations.
  • Control over the experience: The target attribute lets you open links in a new tab or the same tab as needed.
  • Supports images & other content: You can make an image clickable by wrapping it in an <a> tag.
  • Accessible & semantic: Links work with screen readers and keyboard navigation, and wrapping menus in <nav> adds meaning.

6Conclusion

Hyperlinks are what turn separate pages into a connected web. The <a> anchor tag is the tool for creating them, and a single element gives you four kinds of links: internal links between the pages of your own site, external links to other websites, email links that open a message, and anchor links that scroll within the same page. The target attribute adds control over where each link opens.

In summary: use href to choose the destination, and target to choose where it opens. Combine them thoughtfully — a clear <nav> menu, informative link text, and rel="noopener" on new-tab links — and your site becomes easy to navigate, good for search engines, and pleasant to use. As the saying goes: "Links are the glue of the web."
